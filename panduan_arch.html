install arch linux

Arch adalah distro rolling release untuk pengguna yang ingin membangun sistem sendiri. Instalasi manual memerlukan perhatian pada setiap partisi dan perintah.

01 Persiapan dan boot media

  • RAM minimum acuan 512 MB (2 GB atau lebih disarankan), ruang disk 2 GB minimum (20 GB atau lebih disarankan), serta koneksi internet aktif.
  • Cadangkan data, unduh image dari situs resmi Arch Linux, lalu buat USB bootable. Rufus dalam DD mode, Ventoy, atau BalenaEtcher dapat digunakan.
  • Untuk dual boot Windows, cek UEFI/GPT, kecilkan partisi Windows 50–100 GB menjadi ruang Unallocated, dan matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Buat backup dan simpan recovery key terlebih dahulu.
  • Jika SSD/NVMe tidak terdeteksi, periksa Intel RST/RAID. Jangan mengubah mode ke AHCI tanpa mengikuti prosedur persiapan Windows.
  • Nonaktifkan Secure Boot sebelum instalasi Arch. Catat setelan firmware awal dan ikuti kebijakan organisasi jika perangkat dikelola.
  • Restart ke menu boot dan pilih USB. Jika font console terlalu kecil pada layar HiDPI, sesuaikan font sebelum melanjutkan.
  • Pastikan boot UEFI dengan menjalankan cat /sys/firmware/efi/fw_platform_size; pada sistem UEFI 64-bit hasil yang diharapkan adalah 64.

02 Siapkan koneksi dan partisi

Ethernet biasanya tersambung otomatis. Untuk Wi-Fi, nama perangkat (contoh wlan0) dapat berbeda:

iwctl
device list
station wlan0 scan
station wlan0 get-networks
station wlan0 connect "NamaSSID"
exit
ping -c 4 archlinux.org
timedatectl set-ntp true

Periksa disk dengan lsblk -f. Partisi dan format berikut dapat menghapus data; nama disk di contoh hanyalah ilustrasi. Hentikan proses jika belum yakin dengan disk tujuan.

  • Contoh skema UEFI: EFI FAT32 1 GB, swap 4–8 GB, root / 50 GB atau lebih, dan partisi /home untuk sisa ruang.
  • Gunakan cfdisk untuk membuat partisi pada disk yang sudah diverifikasi. Pada dual boot, jangan format atau menghapus partisi Windows.
  • Format dan mount partisi sesuai skema yang dibuat. Jangan menyalin perangkat contoh secara langsung tanpa menggantinya dengan partisi milikmu:
mkfs.fat -F 32 /dev/PARTISI_EFI
mkswap /dev/PARTISI_SWAP
swapon /dev/PARTISI_SWAP
mkfs.ext4 /dev/PARTISI_ROOT
mkfs.ext4 /dev/PARTISI_HOME
mount /dev/PARTISI_ROOT /mnt
mount --mkdir /dev/PARTISI_EFI /mnt/boot/efi
mount --mkdir /dev/PARTISI_HOME /mnt/home

03 Pasang sistem dasar dan konfigurasi

Ganti paket microcode sesuai prosesor: intel-ucode untuk Intel atau amd-ucode untuk AMD.

pacstrap -K /mnt base base-devel linux linux-firmware linux-headers \
  networkmanager vim nano git man-db man-pages intel-ucode
genfstab -U /mnt >> /mnt/etc/fstab
arch-chroot /mnt
ln -sf /usr/share/zoneinfo/Asia/Jakarta /etc/localtime
hwclock --systohc
  • Di dalam chroot, aktifkan locale yang diinginkan di /etc/locale.gen, jalankan locale-gen, lalu atur /etc/locale.conf dan hostname.
  • Buat kata sandi root dan akun pengguna. Tambahkan akun ke grup wheel, lalu buka visudo dan aktifkan aturan sudo untuk grup tersebut.
  • Periksa /etc/fstab dan setiap mount point sebelum mengatur bootloader.

04 Pasang bootloader atau gunakan archinstall

Untuk konfigurasi GRUB UEFI dan EFI terpasang di /boot/efi:

pacman -S grub efibootmgr os-prober
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg
systemctl enable NetworkManager
exit
umount -R /mnt
reboot

Untuk instalasi terpandu, jalankan archinstall. Pilih mirror, konfigurasi disk, bootloader, profil desktop, audio PipeWire, dan akun pengguna melalui menu; tinjau ringkasan disk sebelum memulai.

05 Pasca-instalasi

  • Login sebagai pengguna baru. Contoh desktop KDE Plasma dan display manager SDDM:
sudo pacman -S plasma-meta kde-applications-meta sddm \
  pipewire pipewire-pulse wireplumber
sudo systemctl enable sddm
  • Pilih driver GPU sesuai perangkat dari dokumentasi Arch. Hindari memasang paket driver yang tidak cocok dengan hardware.
  • Perbarui sistem secara berkala dengan sudo pacman -Syu. AUR dikelola komunitas; tinjau PKGBUILD dan sumber paket sebelum memasang.

06 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa UEFI Boot Order dan prioritaskan entri GRUB/Arch. Jika Windows belum muncul di GRUB, ikuti dokumentasi Arch untuk mengatur os-prober.
  • Jika layar hitam muncul setelah pemasangan driver NVIDIA, gunakan opsi boot sementara atau mode pemulihan, lalu periksa driver dan kernel yang sesuai.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, periksa chipset dan firmware yang diperlukan; Fast Startup Windows juga dapat mengganggu perangkat jaringan.
  • Jika jam berbeda pada dual boot, periksa zona waktu dan pengaturan RTC sebelum mengubah perilaku jam hardware.
