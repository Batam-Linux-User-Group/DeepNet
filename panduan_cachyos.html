install cachyos

CachyOS berbasis Arch dan berfokus pada performa. Installer grafis Calamares memandu pemilihan bootloader, filesystem, dan desktop.

01 Persiapan perangkat dan ISO

  • Persyaratan acuan: RAM minimal 2 GB (4 GB atau lebih disarankan), ruang disk minimal 30 GB, dan CPU x86-64 modern.
  • Unduh Desktop Edition untuk PC/laptop atau Handheld Edition untuk perangkat portabel yang didukung dari situs resmi CachyOS.
  • Cadangkan data. Untuk dual boot Windows, cek UEFI/GPT, kecilkan partisi Windows 50–100 GB menjadi ruang Unallocated, dan matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Buat backup dan simpan recovery key terlebih dahulu.
  • Jika installer tidak melihat SSD/NVMe, periksa Intel RST/RAID. Jangan mengubah mode ke AHCI tanpa persiapan Windows terlebih dahulu.
  • Gunakan USB kosong dan Rufus, Ventoy, atau BalenaEtcher. Proses penulisan menghapus isi USB.
  • Nonaktifkan Secure Boot sebelum instalasi CachyOS. Catat pengaturan firmware sebelumnya agar dapat dipulihkan bila diperlukan.

02 Boot ke installer online

  1. Buka Boot Menu UEFI/BIOS, pilih USB, lalu tunggu sampai lingkungan live CachyOS terbuka.
  2. Sambungkan komputer ke internet karena installer online mengambil paket terbaru.
  3. Jalankan CachyOS Installer dari layar sambutan, lalu pilih bahasa, wilayah, dan tata letak keyboard.
  4. Installer dapat mendeteksi dukungan arsitektur CPU; periksa catatan rilis jika perangkat tidak kompatibel.

03 Pilih bootloader, filesystem, dan desktop

  1. Pilih bootloader yang ditawarkan: systemd-boot untuk konfigurasi ringkas, GRUB untuk fleksibilitas dual boot, atau opsi lain yang tersedia.
  2. Untuk instalasi bersih, opsi Btrfs dapat membuat subvolume dan terintegrasi dengan snapshot Snapper. Pastikan disk yang dipilih benar karena penghapusan disk akan menghilangkan data di dalamnya.
  3. Untuk dual boot, gunakan pengaturan manual hanya jika memahami partisi EFI dan filesystem. Jangan memformat partisi Windows atau EFI yang masih dipakai.
  4. Pilih desktop yang diinginkan (misalnya KDE Plasma, GNOME, Hyprland, COSMIC, XFCE, Sway, atau i3) dan paket tambahan.
  5. Masukkan username, hostname, dan kata sandi. Tinjau ringkasan disk sebelum menekan Install.

04 Selesaikan dan optimalkan

  1. Tunggu instalasi selesai, restart, lalu lepaskan USB agar komputer boot ke CachyOS.
  2. Buka CachyOS Hello untuk melihat Apps/Tweaks dan opsi daemon performa. Pasang hanya komponen yang dibutuhkan.
  3. Jika bermain game, menu Apps/Tweaks menyediakan metapackage gaming; daemon seperti ananicy-cpp, systemd-oomd, dan bpftune dapat diaktifkan sesuai kebutuhan.
  4. Gunakan Kernel Manager jika ingin memilih varian kernel lain. Baca keterangan setiap kernel sebelum mengganti kernel aktif.
  5. Perbarui sistem secara berkala:
sudo pacman -Syu

Untuk dual boot atau konfigurasi khusus, rujuk dokumentasi resmi CachyOS sebelum mengubah partisi atau bootloader.

05 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa Boot Order UEFI dan prioritaskan bootloader CachyOS.
  • Jika layar hitam muncul setelah memasang driver GPU, gunakan mode pemulihan dan tinjau driver serta kernel dari dokumentasi CachyOS.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, pastikan Fast Startup Windows nonaktif dan periksa firmware chipset yang dibutuhkan.
  • Jika jam berbeda pada dual boot, periksa zona waktu dan pengaturan RTC sebelum mengubah jam hardware.
