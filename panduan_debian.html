install debian

Debian berfokus pada kestabilan dan bisa dipakai sebagai desktop maupun server. Panduan ini menggunakan alur installer grafis.

01 Pilih image dan siapkan perangkat

  • Debian Stable direkomendasikan untuk penggunaan yang mengutamakan kestabilan. Testing dan Unstable ditujukan untuk pengguna yang memahami risiko paket lebih baru.
  • Persyaratan acuan: RAM minimal 1 GB (2 GB atau lebih disarankan untuk desktop) dan ruang disk minimal 10 GB (20 GB atau lebih disarankan).
  • Unduh image dari situs resmi Debian: Netinst untuk mengunduh paket saat instalasi, DVD-1 untuk media lebih lengkap, atau Live ISO untuk mencoba sesi live.
  • Cadangkan data. Untuk dual boot Windows, cek BIOS Mode lewat msinfo32 dan GPT lewat Disk Management. Kecilkan partisi Windows sekitar 50–100 GB dan biarkan sebagai Unallocated; matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Simpan backup dan recovery key serta pahami dampaknya sebelum mengubah enkripsi.
  • Jika installer tidak melihat SSD/NVMe, periksa apakah Windows memakai Intel RST/RAID. Jangan mengganti mode storage ke AHCI tanpa menyiapkan Windows terlebih dahulu karena dapat membuat Windows gagal boot.

02 Buat USB dan boot installer

  1. Di Rufus, pilih USB dan ISO Debian. Untuk komputer UEFI gunakan GPT dan target UEFI; alternatifnya gunakan Ventoy atau BalenaEtcher.
  2. Menulis image akan menghapus seluruh isi USB. Pastikan perangkat tujuan benar sebelum menekan Start atau Flash.
  3. Restart, buka Boot Menu (umumnya F12, F9, F8, Esc, atau tombol sesuai produsen), lalu pilih USB.
  4. Pilih Graphical install, bahasa, lokasi Indonesia, dan tata letak keyboard. Jika memakai Netinst, sambungkan ke internet.

03 Konfigurasikan installer dan partisi

  1. Biarkan jaringan memakai DHCP bila tersedia, isi hostname (misalnya debian-pc), dan kosongkan Domain Name jika tidak menggunakan domain lokal.
  2. Agar akun utama dapat memakai sudo, biarkan kolom kata sandi root kosong saat instalasi. Jika membuat kata sandi root, akses sudo perlu dikonfigurasi sesudah instalasi.
  3. Pilih Guided - use entire disk hanya untuk instalasi yang menghapus isi disk. Untuk dual boot, pilih partisi manual dan jangan format partisi Windows atau EFI yang akan dipakai bersama.
  4. Acuan partisi UEFI: EFI FAT32 512 MB–1 GB, root / 50 GB atau lebih, swap 4–8 GB (atau sesuai kebutuhan hibernasi), dan /home bila ingin dipisah.
  5. Pilih mirror APT, lalu lingkungan desktop (GNOME, KDE Plasma, XFCE, Cinnamon, MATE, atau LXQt). Pilih SSH server hanya jika diperlukan, serta standard system utilities.
  6. Tinjau ringkasan perubahan disk sebelum menyetujuinya. Konfirmasi pemasangan GRUB pada EFI System Partition, lalu restart dan lepaskan USB saat diminta.

04 Selesaikan konfigurasi awal

Perbarui sistem dan pasang alat dasar dari repositori Debian:

sudo apt update
sudo apt upgrade
sudo apt install build-essential curl wget git ufw flatpak
  • Jika membutuhkan firmware atau driver tambahan, pastikan komponen repositori yang sesuai (termasuk non-free-firmware bila diperlukan) aktif untuk versi Debian yang dipakai, lalu ikuti panduan driver resmi.
  • Jika Windows tidak muncul di menu GRUB, periksa konfigurasi os-prober dan jalankan ulang pembaruan GRUB sesuai dokumentasi Debian.
  • Jika mengatur kata sandi root saat instalasi, ikuti dokumentasi resmi untuk menambahkan akun ke grup sudoers.

05 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa Boot Order UEFI dan pilih entri Debian/GRUB sebagai prioritas.
  • Jika layar hitam muncul setelah memasang driver NVIDIA, gunakan mode pemulihan atau parameter boot sementara sesuai dokumentasi Debian, lalu pasang driver yang cocok.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, pastikan Fast Startup Windows nonaktif dan pasang firmware yang sesuai dengan chipset.
  • Jika jam berbeda antara Windows dan Linux, periksa zona waktu serta konfigurasi RTC sebelum mengubah format jam hardware.
