install kali linux

Kali Linux dirancang untuk pengujian keamanan, audit, dan forensik; bukan distro desktop umum. Untuk belajar, pertimbangkan menjalankannya di mesin virtual terlebih dahulu.

01 Pilih image dan siapkan perangkat

  • Persyaratan acuan: RAM minimal 2 GB (4 GB atau lebih untuk penggunaan tools berat) dan ruang disk minimal 20 GB; profil tools besar membutuhkan lebih banyak ruang.
  • Unduh dari situs resmi Kali Linux dan verifikasi image mengikuti panduan resmi.
  • Installer Image untuk instalasi tetap, Live Image untuk boot langsung dari USB (termasuk opsi persistence), dan Everything Image untuk koleksi paket offline yang besar.
  • Cadangkan data. Untuk dual boot Windows, cek UEFI/GPT, kecilkan partisi 50–100 GB menjadi ruang Unallocated, dan matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Buat backup dan simpan recovery key terlebih dahulu.
  • Jika installer tidak melihat SSD/NVMe, periksa Intel RST/RAID. Jangan mengubah mode ke AHCI tanpa persiapan Windows terlebih dahulu.

02 Buat USB dan mulai installer

  1. Buat USB dengan Rufus, Ventoy, atau BalenaEtcher. Pastikan USB yang benar dipilih karena seluruh isinya akan dihapus.
  2. Restart komputer, buka Boot Menu, lalu pilih USB Kali Linux.
  3. Pilih Graphical install, kemudian bahasa, lokasi, zona waktu, keyboard, jaringan, dan hostname (default biasanya kali).
  4. Buat akun pengguna standar dan kata sandi. Kali modern tidak menggunakan akun root default; gunakan sudo untuk tugas administratif.

03 Partisi dan pilih paket

  1. Guided - use entire disk menghapus sistem dan data di disk tujuan. Verifikasi disk yang dipilih sebelum melanjutkan.
  2. Opsi All files in one partition lebih sederhana. Partisi terpisah untuk /home, /var, atau /tmp ditujukan untuk kebutuhan yang lebih khusus.
  3. Pilih desktop yang diinginkan (XFCE adalah pilihan default yang umum) dan koleksi metapackage sesuai ruang disk: top10, default, atau large.
  4. Setujui pemasangan GRUB pada disk utama yang benar. Tinjau perubahan partisi, tunggu instalasi, lalu restart dan lepaskan USB.

04 Perbarui dan gunakan dengan bertanggung jawab

Setelah masuk ke sistem, pasang pembaruan keamanan:

sudo apt update
sudo apt full-upgrade
  • Gunakan kali-tweaks untuk pengaturan desktop, SSH, dan metapackage yang tersedia.
  • Pasang driver hanya dari sumber resmi dan sesuai perangkat.
  • Gunakan alat keamanan hanya pada perangkat, akun, dan jaringan milik sendiri atau yang sudah mendapat izin tertulis.

05 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa Boot Order UEFI dan prioritaskan entri Kali/GRUB.
  • Jika layar hitam muncul setelah memasang driver NVIDIA, gunakan mode pemulihan atau opsi boot sementara, lalu pasang driver dari dokumentasi resmi.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, periksa chipset dan firmware yang sesuai; Fast Startup Windows juga dapat mengunci perangkat jaringan.
  • Jika jam berbeda pada dual boot, periksa zona waktu dan konfigurasi RTC sebelum mengubah perilaku jam hardware.
