install linux mint

Linux Mint mengutamakan kemudahan penggunaan dan stabilitas. Ikuti persiapan dan langkah instalasi ini sebelum mengubah partisi.

01 Pilih edisi dan siapkan perangkat

  • Cinnamon adalah edisi standar; MATE menawarkan desktop klasik, XFCE lebih ringan untuk perangkat lama, dan LMDE berbasis Debian Stable.
  • Persyaratan acuan: RAM minimal 2 GB (4 GB disarankan) dan ruang disk minimal 20 GB (100 GB disarankan).
  • Unduh ISO dari situs resmi Linux Mint. Cocokkan checksum SHA256 dengan berkas resmi sebelum membuat USB.
  • Cadangkan data. Untuk dual boot Windows, cek BIOS Mode lewat msinfo32 dan GPT lewat Disk Management. Kecilkan partisi Windows sekitar 50–100 GB dan biarkan sebagai Unallocated; matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Simpan backup dan recovery key serta pahami dampaknya sebelum mengubah enkripsi.
  • Jika installer tidak melihat SSD/NVMe, periksa mode Intel RST/RAID. Jangan mengganti ke AHCI tanpa menyiapkan Windows agar sistem tetap bisa boot.

02 Buat USB dan uji sesi live

  1. Gunakan Rufus dengan GPT/UEFI, Ventoy, atau BalenaEtcher untuk menulis ISO ke USB kosong. Proses ini menghapus isi USB.
  2. Restart, buka Boot Menu, lalu pilih USB untuk masuk ke desktop live Linux Mint.
  3. Sebelum memasang, uji Wi-Fi, suara, keyboard, touchpad, dan tampilan agar masalah perangkat keras terlihat lebih awal.
  4. Klik dua kali ikon Install Linux Mint di desktop untuk membuka installer.

03 Atur installer dan jenis instalasi

  1. Pilih bahasa dan tata letak keyboard. Centang Install multimedia codecs jika menginginkan codec tambahan.
  2. Erase disk and install Linux Mint akan menghapus disk yang dipilih. Gunakan hanya jika memang ingin instalasi bersih.
  3. Install alongside Windows Boot Manager dapat membantu dual boot; periksa alokasi ruang yang ditampilkan sebelum melanjutkan.
  4. Something else adalah partisi manual. Untuk dual boot, pertahankan partisi Windows dan EFI yang ada; jangan centang format untuk partisi yang ingin disimpan.
  5. Atur nama, username, dan kata sandi. Enkripsi folder home bersifat opsional; simpan kata sandinya dengan aman.
  6. Tinjau perubahan disk sebelum memilih Install Now. Tunggu selesai, pilih Restart Now, lalu lepaskan USB saat diminta.

04 Pembaruan dan perawatan awal

  • Buka Update Manager, pilih mirror lokal yang tepercaya bila ditawarkan, lalu pasang pembaruan yang tersedia.
  • Buka Driver Manager untuk memeriksa driver yang direkomendasikan bagi GPU, prosesor, atau adaptor Wi-Fi.
  • Atur Timeshift untuk membuat snapshot sistem, pilih lokasi penyimpanan yang sesuai, dan aktifkan jadwal yang diinginkan.
  • Jika ingin mengaktifkan firewall dan pengelola daya laptop:
sudo ufw enable
sudo apt install tlp tlp-rdw
sudo tlp start

05 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa Boot Order UEFI dan pilih Linux Mint/GRUB sebagai prioritas.
  • Jika layar hitam muncul setelah memasang driver NVIDIA, gunakan mode pemulihan atau panduan driver resmi untuk memasang versi yang cocok.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, pastikan Fast Startup Windows nonaktif dan periksa driver/firmware perangkat di Driver Manager.
  • Jika jam berbeda antara Windows dan Linux, periksa zona waktu serta konfigurasi RTC sebelum mengubah format jam hardware.
