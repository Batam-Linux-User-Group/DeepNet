install pop!_os

Pop!_OS berbasis Ubuntu LTS dan ditujukan untuk produktivitas, STEM, dan gaming. Pilih ISO sesuai GPU sebelum memulai.

01 Pilih ISO dan siapkan perangkat

  • Persyaratan acuan: RAM minimal 4 GB, penyimpanan minimal 20 GB (100 GB atau lebih disarankan), dan sistem 64-bit.
  • Unduh dari situs resmi System76. Pilih ISO NVIDIA untuk perangkat dengan GPU NVIDIA; gunakan Intel/AMD ISO untuk grafis Intel atau AMD.
  • Cadangkan data. Untuk dual boot Windows, cek UEFI/GPT, kecilkan partisi Windows 50–100 GB menjadi ruang Unallocated, dan matikan Fast Startup. Jika installer perlu mengakses partisi Windows, BitLocker mungkin perlu dinonaktifkan. Buat backup dan simpan recovery key terlebih dahulu.
  • Jika installer tidak melihat SSD/NVMe, periksa Intel RST/RAID. Jangan mengubah mode ke AHCI tanpa persiapan Windows terlebih dahulu.
  • Nonaktifkan Secure Boot sebelum instalasi Pop!_OS karena alur boot-nya menggunakan systemd-boot. Catat setelan BIOS sebelum mengubahnya.
  • Buat USB dengan BalenaEtcher, Rufus (DD mode jika ISO tidak boot dalam mode standar), atau Ventoy.

02 Boot ke installer

  1. Restart, buka Boot Menu UEFI, lalu pilih USB Pop!_OS.
  2. Pilih bahasa, wilayah, dan tata letak keyboard. Uji koneksi dan perangkat keras utama dari lingkungan live.
  3. Pilih mode Clean Install untuk instalasi pada disk kosong atau Custom (Advanced) untuk pengaturan manual.

03 Pilih partisi dan enkripsi

  • Clean Install menghapus isi disk yang dipilih dan membuat partisi sistem, termasuk partisi Recovery sekitar 4 GB.
  • Untuk dual boot, gunakan Custom (Advanced). Buat partisi EFI terpisah untuk Pop!_OS, minimal 1024 MB (FAT32), agar tidak bergantung pada ruang EFI Windows yang kecil.
  • Jika tidak memahami partisi EFI, mount point, atau format, jangan lanjutkan pengaturan manual. Tinjau ringkasan partisi dan pastikan partisi Windows tidak diformat.
  • Buat akun pengguna. Enkripsi disk LUKS bersifat opsional; bila diaktifkan, simpan kata sandi dekripsi di tempat aman.

04 Selesaikan dan atur sistem

  1. Konfirmasi instalasi hanya setelah memeriksa disk dan partisi. Tunggu selesai, klik Restart Device, lalu lepaskan USB.
  2. Selesaikan wizard awal untuk dock, top bar, gestur touchpad, dan privasi.
  3. Di desktop COSMIC, Auto-Tiling dapat diatur dari ikon Tiling; gunakan Super + Y untuk tiling dan Super + Enter untuk pengaturan jendela.
  4. Untuk laptop hybrid, pilih satu mode grafis melalui System76 Power: sudo system76-power graphics integrated untuk hemat daya, sudo system76-power graphics nvidia untuk performa, atau sudo system76-power graphics hybrid untuk mode dinamis.

05 Troubleshooting umum

  • Jika komputer langsung masuk Windows, periksa Boot Order UEFI dan prioritaskan entri Pop!_OS/systemd-boot.
  • Jika layar hitam muncul, pastikan ISO sesuai GPU; untuk NVIDIA, gunakan image dan petunjuk driver resmi System76.
  • Jika Wi-Fi/Bluetooth tidak terdeteksi, periksa firmware chipset dan pastikan Fast Startup Windows nonaktif.
  • Jika jam berbeda pada dual boot, periksa zona waktu dan pengaturan RTC sebelum mengubah jam hardware.
